# Arithmetic Operators
These operators are recognized. Their operand types, result types, and edge-case behavior are not yet specified.

| Operator | Name |
|---|---|
| `+` | Addition |
| `-` | Subtraction |
| `*` | Multiplication |
| `/` | Division |
| `%` | Modulus |
| `**` | Exponentiation |

**Arithmetic semantics:** Arithmetic operations work on `Integer` and `Float`. If a `Float` is mixed with an integer in an expression, integers are automatically cast to `Float`, excepting modulus. Arithmetic expressions with only `Integer` types result in an `Integer`.

**Precedence and associativity:** Arithmetic operators follow standard mathematical rules. The `!` operator executes before the equality operator. Eventually, we expect our operators to be implemented according to this table. *Do not implement an operator unless explicitly instructed to do so.*

| Precedence | Operator | Description | Associativity |
| :--- | :--- | :--- | :--- |
| **1 (Highest)** | `new` | Object instantiation | Non-associative |
| **2** | `**` | Exponentiation | Right |
| **3** | `++`, `--` | Increment/decrement | Non-associative |
| **4** | `isa` | Type check | Non-associative |
| **5** | `!` | Logical NOT | Non-associative |
| **6** | `*`, `/`, `%` | Multiplication, division, modulo | Left |
| **7** | `+`, `-`, `.` | Addition, subtraction, string concatenation | Left |
| **8** | `<`, `<=`, `>`, `>=` | Less than, greater than comparisons | Non-associative |
| **9** | `==`, `!=` | Equality, and non-equality | Non-associative |
| **10** | `&&` | Logical AND | Left |
| **11** | `\|\|` | Logical OR | Left |
| **12** | `if <epression> then <value> else <value>` | Ternary conditional | Non-associative  |
| **13** | `=` | Assignment operator | Right |
