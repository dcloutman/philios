# Defining Classes
Philios allows users to define classes. Classes group data and properties together. A class is an abstract definition of an object type. Classes instantiate objects via a class method.

## Declaration
Classes are defined in a block with the `class` keyword. The syntax for this for a simple class declaration is `class <class-name>`. To declare the class Foo with no properties or methods, one writes:

```philios
class Foo:
    pass
```

## Inheritance
Philios implements single class inheritance, so a class can only inherit from a single parent class. Inheritance is defined with the `extends` keyword. If the `extends` keyword is ommitted, then the class automatically descends from `Object`. The simple class declaration example from above could be explicitly rewritten, without changing its meaning, as:

```philios
class Foo extends Object:
    pass
```

A simple inheritance tree where `Foo` inherits from `Object` and `Bar` inherits from `Foo` would be written as:

```philios
class Foo:
    pass

class Bar:
    pass
```

#### Internal References

Reserved the keywords: `this`, `self`, and `definer`.

| Keyword & Operator | Valid Contexts | Resolution Target | Binding Time |
| :--- | :--- | :--- | :--- |
| `this->member` | Instance methods only | Current object instance | Runtime (Dynamic) |
| `self::member` | Instance & Static methods | Runtime class of the receiver | Runtime (Late Static Binding) |
| `definer::member` | Instance & Static methods | Lexically enclosing class | Compile time (Early Binding) |
