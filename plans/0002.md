# `null`, `String` and `Integer` Implementations and `echo()` and `typeof()` Pseudo-Functions
All types in Philios extend a base `Object` class.

## Pseudo-Functions
A pseudo-function is a built-in language construct. Unlike user-defined functions, it does not extend the `Function` base class. (The `Function` base class is a feature that will be implemented in a later plan.) For now, just understand the pseudo-functions will be limited in how they can be extended in future implementations. Attempting to determine the type of a pseudo-function should produce an error. One cannot extend a pseudo-function.

### `echo()`
`echo` is a pseudo-function that takes a string as an argument and outputs its contents to the program's output. It does not prepend or append the string.

Example:
```philios
function main(): Integer:
    echo("Hello World")
    return 1
```

This code must output "Hello World" for this plan to be considered fully implemented.

### `typeof()`
Returns a string of the variable's declarated type or the type of a string literal.

Example:
```philios
function main(): Integer:
    echo(typeof("Hello World"))
    return 1
```

This code must output "String" for this plan to be considered fully implemented.

Example:
```philios
function main(): Integer:
    echo(typeof(1))
    return 1
```

This code must output "Integer" for this plan to be considered fully implemented.


## `Object`
`Object` cannot be instantiated on its own. As a type, it can be used to signify any type. This can be useful in data structures that need to store a mixture of types.

## `null`
`null` is an object instance of the `NullObject` class, which extends the `Object` class. It is created at runtime as a singleton instance of `NullObject`.

### Filtering `null` Types
Declaring a parameter or a data structure as accepting `Object` comes with a caveat. It allows the use of `null` values. To filter `null` in this case, use the `not()` pseudo-function. E.g. `foo: Array[Object not(NullObject)] = []`. The interpreter should accept `not(null)` as an alias of `not(NullObject)`.

## `String` and `Integer` Inheritance
`String` and `Integer` should extend `Object`. Both `String` and `Integer` are immutable types. Immutable types must descend from `ImmutableObject`, which extends `Object` and implements the `ImmutableObjectInterface`.

## Negative Integer Support
Support the declaration of negative `Integer` literals.

Example:
```philios
function main(): Integer:
    return -1
```

This code must return -1 to the shell for this plan to be considered fully implemented.
