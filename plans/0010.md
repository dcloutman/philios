# Core Data Structures
These are the core data structures that will ship with Philios 1.0.
- **Array:** These are true arrays that behave like C or C++ array structures. They have a fixed lenth can cannot be changed. Individual members can change, but a member cannot be appended or removed without a replacement that matches its member type. No change can alter the length of an `Array`. Internally, these should probably be implemented as standard C arrays. The goal of an `Array` type is speed where the complexity of usage is minimal. An `Array` of 10 strings would be declared as follows: `foo[10]: Array[String]`. Each member has a numeric index. The first index is 0. Literal assignments are accomplished with brackets (`[]`). The size needn't be declared if the a literal is used to assign values to the array when when variable is declared. E.g. `foo: Array[Integer] = [1, 2, 3]`. The length is determined by the number of members in the literal.
- **`List`:** Lists behave similarly to arrays, except their size is dynamic. There behavior is similar to the `List` type in Python. Each member has a numeric index. The first index is 0. A member can be added to a `List` using the `append()` method. Alternately, the shorthand, `myList[] = "New string."` will append the list as well. The last member can be removed via the `pop()` method, which returns the value of the deleted item. The `slice()` method removes members within the specified range. Internally, `List` items are stored as pointers in an array that is periodially resized. This optimizes for fast lookup at the cost of RAM. **Do not implement with a linked list.** Follow Python's implementation as an example.
