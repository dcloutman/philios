## `bound` Blocks
`bound` blocks allow developers to scope temporary variables in an otherwise undistinguished block.

```philios
function main(): Integer:
    bound:
        let output: String = "Hello World"
        echo(output) // Should print "Hello World"

    // `bound` block ends and `output` is deleted.
    echo(output) // Should throw an error.
```

## The `while` Loop
A while loop loops while its condition is true. The loop's block is declared with the syntax, `while (<some-condition>):`. Parentheses are optional.

## Casts
Casting a value from one type to another is done with the syntax, `(<desired-type>) <source-variable>`. Both `Integer` and `Float` should be able to cast to `String` and `Integer` should be able to cast to `Float`.

This example will should function after this plan is complete.

```philios
function main(): Integer:
    // Counts to 5.
    let i: Integer = 0
    while i < 5:
        echo((String) i + 1 . "\n")
        i = i + 1
```

It should output:
```
1
2
3
4
5
```
