# Functions are Objects
Every function is an object of the type `Function` which extends `Object`.

A function name, once declared, is a constant. Assigning a function name to a variable sets that variable to a reference to the function.

```philios
function f1 (param1: String): String:
    return param1

function main (): Integer:
    someFunction: Function = f1 // This is a  reference to `f1`. `f1` is not called.
    someFunction("text") // Calls `f1`.
    return 0
```

## The `function` Keyword is Semantic Sugar For a Functor
Functions are objects that extend `Function`. The declaration of `f1`, above, is shorthand for:

```
Function f1 = new (class extends function:
    public function invoke(param1: String): String:
        return param1
)
```

This allows functions to be written as objects with internal constants and helper methods declared as protected or private. Only `invoke()` may be public. Other userland `public` declarations are forbidden. Users cannot declare a constructor. The internal constructor for `Function` runs automatically. `Function` is not a general purpose base class.

It is perfectly legal to extend a function class and override any of its protected constants, methods or properties, other than the constructor. Any class that has Function in its iheritance tree is subject to the same restrictions as its parent.
