# Philios

Philios is a fully typed, interpreted, fully scripted programming language.

## Features
- Types are enforced at runtime
- Modular programming
- OOP (Single class inheritance)
- Block-level scoping
- Built-in garbage collection
- No global variables
- Every variable is an object, though some objects are immutable

## Inspriations
- Indentation demarcates blocks (4 spaces) (Python)
- Single class inheritance (Java, PHP)
- Mixed programming paradigms (C++ / PHP)
- Modules (Node JS, Python)
- Pythonic data types

## Goals
- Type safety
- Speed
- High level of readability
- Approachable for users of other language
- One reasonable way to do most things
- Easy to extend the language through libraries

## Directories
- `src`: The interpreter source code, make file, etc.
- ``docs`: Language rules, developer documentation, example projects.
- `bin`: The target directory for the resulting binary.
