# Philios Programming Language

*Philios is a general-purpose, interpreted, staticly typed programming language.*

**Philios** borrows the best aspects of other high-level programming language to allow developers to create highly readable, extensible, and maintainable software. It allows for a mixture of programming paradigms and uses modules to isolate different units of code and manage programmatic APIs.

**Philios** is a 21st century programming language that uses both Artificial Intelligence (AI) and deterministic tooling to rapidly build features, verify functionality, and enforce security. It is implemented using modern C++ paragims. Its source code is open and its development process is transparent.

**Philios** is Internet-ready with asyncronous functions and methods built-into the language's core.
