# Getting Started: Required Tools

The following tools are required to develop `philios`:

- **`git`**
- **Bash** in a POSIX environment (Linux or WSL)
- **GCC 13+** (the supported compiler baseline)
- **`cmake`**
- **`clang-tidy` 18+**
- **Catch2 3.16.1** (test-only dependency, resolved by CMake)
- **Python 3.11+** (for AI loop helpers)
