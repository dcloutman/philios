# Getting Started: Required Tools

The following tools are required to develop `philios`:

- **`git`:** Required to clone the repository.
- **C++ compiler:** A compiler that supports the C++20 standard is required. The project does not target a specific compiler.
- **Build tools and dependencies:** 
  - `cmake`
  - `clang`
  - `clang-tidy`
  - `scan_build` Clang's static analysis tool.
  - Catch 2 for unit testing.
- **Additional tools for AI loop**
  - Python v3.11.0 or later
